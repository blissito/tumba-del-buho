# La Tumba del Búho - Landing Page

## Descripción
Landing page informativa sobre el descubrimiento arqueológico de la Tumba 10 de Huitzo, Oaxaca. Incluye un chatbot Formmy.app que responde preguntas sobre el hallazgo.

## Stack Técnico
- **HTML5** con **Tailwind CSS** (via CDN)
- **Formmy.app** widget embebido
- **Hosting**: GitHub Pages

## Archivos Principales
| Archivo | Propósito |
|---------|-----------|
| `index.html` | Landing page principal |
| `tumba-buho-conocimiento.md` | Base de conocimiento para el agente |
| `CLAUDE.md` | Este archivo - contexto del proyecto |

## Configuración Formmy
- **Slug**: `blog-test-agent-hCXoSU`
- **Template**: `minimal`
- **Host**: `https://formmy.app`

## Tema Visual
- Colores: obsidian (#0a0a0a), gold (#d4a853), jade (#2d5a4a), cream (#f5f0e6)
- Fuentes: Cinzel (títulos), Crimson Text (cuerpo)
- Estilo: Mesoamericano/arqueológico con toques dorados
